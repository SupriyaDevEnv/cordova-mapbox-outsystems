Touch routing demo

The canvas is the "native map". The page on top is transparent. A simulated native router sends each gesture to the map or the page when the pointer goes down.

Routing strategy

Hit-test grid and Element scan apply the same rule (anything visible over the map belongs to the page). Element scan checks each page element once instead of sampling a grid of points.

Try these (switch strategy and repeat)

  1. Tap a filter chip, then drag the chips row sideways.
